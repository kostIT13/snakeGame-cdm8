# Snake Game (Logisim + CDM-8)

Аппаратно-программная реализация игры **Snake**, разработанная в среде **Logisim** с использованием процессора **CDM-8** и программы на **Assembler CDM-8**.

## Описание проекта

Проект представляет собой классическую игру **«Змейка»**, реализованную на основе цифровой логики. Игровая логика выполняется процессором **CDM-8**, а визуализация и аппаратная часть реализованы в **Logisim**.

## Основные возможности

- Управление змейкой с клавиатуры
- Генерация яблок
- Подсчёт очков
- Экран начала игры и `GAME OVER`
- Взаимодействие `Hardware ↔ Software` через `memory-mapped I/O`

## Структура проекта

- `snake.asm` — программная логика игры
- `main` — главный модуль
- `Movement` — обработка движения
- `Keyboard` — управление
- `DataScreen` — хранение состояния поля
- `UpdateScreen` — обновление дисплея
- `CDM-8` — процессор выполнения программы

## Технологии

- **Logisim**
- **Assembler CDM-8**
- **Harvard Architecture**
- **Memory-Mapped I/O**

##### Адреса регистров логисим:

###### Output: 
	0xf0 - value
	0xf1 - stop
	0xf2 - head x
	0xf3 - head y
	0xf4 - tail x
	0xf5 - tail y

	0xf6 - update screen
	
###### Input:
	0xf8 - head x
	0xf9 - head y
	0xfa - tail x
	0xfb - tail y
	0xfc - apple x
	0xfd - apple y
	0xfe - direction
